# Демонстрационные измерения

CSV содержат неизменённые строки за 25–31 января 2026 года из предоставленных
организаторами HackAlem AI файлов двух турбин: по 1008 строк на турбину.
Это реальные измерения, не синтетические данные и не полный датасет.
Условия распространения исходных данных отдельно в ТЗ не указаны.

Примеры используются в тестах; автоматически в приложение не импортируются.
Для ручной проверки сначала создайте турбину и загрузите CSV через веб.
