# NoIdea · Прогнозирование выработки ВЭС

Проект команды NoIdea для HackAlem AI: прогноз почасовой мощности двух
ветротурбин на горизонте 24–48 часов с агентным управлением расчётом.

## Первый этап: данные и веб-интерфейс

- Импорт измерений турбин: ветер, нормализованная мощность и температура.
- Проверка пропусков, дубликатов и полноты почасовых данных.
- Получение отдельных архивных выпусков прогноза погоды Open-Meteo / ECMWF.
- Веб-страница с графиками, качеством данных и выбором погодного выпуска.

Реализация находится в разработке. Этот коммит фиксирует направление работы;
инструкции запуска появятся вместе с проверенной рабочей версией.

## Данные и ограничения

Предоставленные измерения охватывают 11.03.2023–31.01.2026.
Тестовый период по ТЗ — февраль 2026; фактических измерений за него в CSV нет.

Для исторических расчётов нужны прогнозы погоды, доступные на момент расчёта.
Время инициализации погодной модели не равнозначно времени публикации выпуска.
Часовой пояс исходных измерений требует подтверждения; предполагаемый —
Asia/Almaty, с учётом изменения смещения в марте 2024 года.

API-ключи хранятся локально в `.env`. Рабочие данные, кеши и секреты исключены
из Git. Для первого этапа ключ LLM не требуется.

## Планируемый стек

Python 3.12, uv, FastAPI, Parquet, SQLite, React, Docker Compose.

Источник погоды: [Open-Meteo Single Runs API](https://open-meteo.com/en/docs/single-runs-api).
